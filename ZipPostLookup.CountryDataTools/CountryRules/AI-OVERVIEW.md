# Validation — AI Overview

_Generated by automated architecture audit. Snapshot of structure & concerns, not authoritative spec._

**Role:** Per-country domain rules (`ICountryRules`) for the CDT pipeline (special-code domains, admin1 derivation, API routing, place-name languages) plus the shared place-name normalizer. (Distinct from the library's `ZipPostLookup.Normalizers.ICountryCodeRules`, which is format/normalise only.)

## Files
| File | Responsibility | Notes / concerns |
|---|---|---|
| `ICountryRules.cs` | Domain contract; many default-interface-method members | `ResolveAdmin1` presence is reflection-sniffed externally (see below). |
| `CountryRulesFactory.cs` | `For(string)` / `For(PipelineCountry)` → Us/Ca/Mx/Null | `For(string)` allocates a fresh rules object each call (rules are stateless — could cache singletons). |
| `NullCountryRules.cs` | No-op fallback; `Country => US` sentinel | Doesn't override the optional members (relies on interface defaults). |

| `Us/UsCountryRules.cs` | APO/FPO/PR/territory ranges; SCF-prefix `_prefixMap` (~700 lines); Armed-Forces enrichment; Zippopotam routing | Huge hardcoded prefix table; `IsOutOfBoundsUs` is the canonical US-bounds rule but is bypassed — the runtime purge restates the bounds in SQL (`CommonQueries`, sync-comment). Source-of-truth duplication, not dead code. |
| `Ca/CaCountryRules.cs` | FSA-first-letter→province map; FSA API-code truncation; EN/FR langs | `ResolveAdmin1` deliberately present (triggers integrity admin grading). |
| `Mx/MxCountryRules.cs` | Estado-by-ZIP-range `ResolveAdmin1`; ES langs | Clean range switch. |

## Structural & duplication concerns
- **`ResolveAdmin1` reflection coupling:** three call sites (`CdtDbIntegrityCommand`, `Analyse/AnalysisContext`, `WorkDbCommand`) detect "does this country derive admin1?" via `rules.GetType().GetMethod(nameof(ResolveAdmin1)).DeclaringType != typeof(ICountryRules)`. Fragile, duplicated 3×, and forces CA's analysis-layer map to stay *out* of `CaCountryRules` to avoid tripping it.
- Us/Ca/Mx repeat the same five trivial `=> false/null` members for the special-domain methods.
- Two parallel admin1 mechanisms: range/prefix (`ResolveAdmin1`) and name→code (`ResolveAdmin1CodeFromName`, CA only) — fine but undocumented as a pair.

## Recommendations
- Replace the reflection sniff with an explicit `bool SupportsAdmin1Derivation { get; }` (default `false`) on `ICountryRules`; have Us/Ca/Mx opt in. Removes all 3 reflection sites and the CA-promotion landmine.
- Cache the three rules instances as singletons in the factory.
- Keep `IsOutOfBoundsUs` as the source of truth (consistent with Ca/Mx rules owning their country logic); eliminate the C#/SQL duplication by deriving the purge SQL bounds from a `UsCountryRules` constant, or by exercising the method in a C# validation path. Do not delete it.
